Training on all four datasets lifts the student from 29.8% to 65.5% judge-correct (+35.6 pts, 95% CI [+31.7, +39.4]), reaching 91% of the teacher's 72.3% with no teacher at inference. The live-teacher arm reaches 60.5% (84% of the teacher), so the trained student is 5.0 pts better than the same student helped by the teacher at every step (CI [+1.6, +8.3]), at less than half the tokens. On StrategyQA both student arms edge past the teacher (74.1% and 75.1% vs 71.9%); on MuSiQue, the hardest set, the trained and guided students tie at 42.4%. The teacher stays ahead of the trained student by +6.8 pts (CI [+3.4, +10.3]).

Protocol and coverage

  • Test set. HotpotQA 189, 2WikiMultihopQA 170, MuSiQue 203, StrategyQA 185 = 747 questions: the 10% held-in pool of each dataset (sha256-salted split), excluded from every training fold including this all-4 fold.
  • Student decoding. Greedy (T=0), seed 13, budget 3 with the budget hidden from the agent; identical prompts, tools and per-question corpus for all arms.
  • Teacher. edenchat/flexai/DeepSeek-V4-Flash-0731 for both the guided arm and the teacher-alone arm, so the reference and the helper are the same model.
  • Judge. base: Kimi-K2.6 ×18,956, MiniMax-M3-MXFP8 ×28; uniform: Kimi-K2.6 ×1,494; teacher: Kimi-K2.6 ×1,755. The judge sees question, gold and final answer only.
  • Training. LoRA r32/α64, 2 epochs, lr 1e-4, effective batch 16, 14,477 examples from correct episodes only; final train loss 0.348, dev loss 0.269.
  • Guided arm. 6 episodes in flight; the student ran on the same vLLM server as the other student arms.

Caveats

  • One seed, one budget. Bootstrap CIs cover question sampling, not decoding or training variance.
  • Guided-arm plan-phase tokens and their teacher cost are not logged (see §3); its true token and API cost per episode is somewhat higher than shown.
  • GPU cost uses an assumed hourly rate; the teacher API price is EdenAI's reported per-call cost at run time.
  • The judge is a single model; EM/F1/cover are shown alongside so the reader can check it is not systematically generous to any arm.
