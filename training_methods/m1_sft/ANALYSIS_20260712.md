# m1_sft full-run analysis — 2026-07-12 (run 20260712T022817Z)

Guidance-as-internal-thought SFT of `granite-4.1-3b` (LoRA r=32, 2 epochs, 4×A100 DDP,
1h49m) on the FIXED dataset (17,961 train / 544 dev examples; empty `decision.category`
dropped from targets; plan-review score-0.0 miscalibration removed). Train loss 0.428,
eval loss 0.347, token accuracy 88.6%.

## The three eval arms (budget 4, greedy, HF bf16, teacherless prompts identical)

| arm | teacher at eval | dev EM | dev F1 | dev cover | dev doc-recall | golden cover |
|---|---|---|---|---|---|---|
| base | none | 2.4% | 0.092 | 18.1% | 0.669 | 2.0% |
| **m1 (internalized)** | none | **26.5%** | **0.368** | **67.5%** | 0.771 | 7.0% |
| m1 + real teacher | gpt-oss-120b in loop | 26.5% | 0.372 | **75.9%** | **0.813** | 8.0% |

dev = 83 held-out questions (same distribution as training, never trained on).
golden-100 = the hardest never-solved questions (base ≈ 0 by construction).

## Findings

1. **Internalization works.** +49 points cover-match on dev (18.1 → 67.5) with zero
   teacher calls. The model self-generates teacher-style guidance, then acts on it.
   It newly solves 43 of 83 dev questions vs base and loses only 2.
2. **The internalized student nearly matches the live-teacher trace runs.** The in-loop
   teacher judged 65/83 (78.3%) of the m1 student's final dev answers correct at
   budget 4 — the untrained student needed budget 9 (+ hidden budget) to reach 78.4%
   in the b-run sweep, and got 75.2% at budget 5.
3. **A live teacher still adds retrieval quality but little correctness.** +8.4 cover
   points (10 questions gained, 3 lost), doc-recall 0.771 → 0.813, but EM unchanged —
   teacher-accepted answers tend to be verbose sentences that cover the gold answer
   without exact-matching it. The teacher's remaining value is mostly reject_finish
   (46 rejections across 83 episodes) forcing another retrieval round.
4. **Format adherence is a training outcome too.** Invalid-action steps: base 51 (dev) /
   61 (golden) — the m1 model: 2 / 0. Voluntary finishing also flips: base ends 75% of
   episodes with no finish at all; m1 commits an answer in ~99% of episodes.
5. **Self-guidance scores are now calibrated.** The generated `teacher_guidance.score`
   spans the range (mode 0.2 early-episode, 0.9–1.0 when evidence is in hand; mean
   0.42) — the previous run's degenerate "score 0.0 + praise" pattern is gone (that
   was inherited from the stored plan-review default and is now excluded from targets).
6. **Golden-100 moved for the first time.** m1 alone cover-matches 7/100; with the
   live teacher 8/100, of which **4 were judged outright correct by the teacher** —
   these questions were never solved in ANY of the 18k teacher-guided trace episodes.
   Doc-recall on golden is high for every arm (0.73–0.84): retrieval isn't the wall,
   multi-hop synthesis is.

## Caveats

- Cover-match can overcredit verbose answers; EM/F1 undercredit them. Read the three
  together (or use the teacher-verdict judge for a semantic metric).
- The b-run numbers were collected with Ollama Q4 student + sampled decoding; these
  arms use HF bf16 greedy. Compare within-harness where possible.
- One m1 dev episode ended `budget_forced_finish_no_finish` — the failure mode isn't
  fully gone, just rare.
