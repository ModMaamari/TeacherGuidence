# HotpotQA — Teacher Guidance datasets

Generated by `scripts/prepare_hotpot_teacher_guidance.py`.

## Files

- `hotpot_<subset>_<split>_questions.jsonl` — one row per QA task. The `gold`
  object (answer, supporting titles/facts, gold doc ids) is **teacher-private** and
  must never be placed in a student prompt.
- `hotpot_<subset>_<split>_corpus.jsonl` — one row per paragraph/document. The
  `hotpot_local` retriever searches only within a question's `candidate_doc_ids`.

## Question row

```json
{
  "id": "5a87...",
  "query": "...",
  "answer": "Delhi",
  "type": "bridge",
  "level": "medium",
  "gold": {
    "answer": "Delhi",
    "supporting_titles": ["Oberoi family", "The Oberoi Group"],
    "supporting_facts": [{"title": "Oberoi family", "sent_id": 0}],
    "gold_doc_ids": ["5a87...::doc1", "5a87...::doc6"]
  },
  "retrieval_scope": {
    "backend": "hotpot_local",
    "qid": "5a87...",
    "candidate_doc_ids": ["5a87...::doc0", "..."]
  }
}
```

## Corpus row

```json
{
  "doc_id": "5a87...::doc1",
  "qid": "5a87...",
  "title": "Oberoi family",
  "text": "...",
  "sentences": ["..."],
  "is_gold_doc": true,
  "gold_sent_ids": [0],
  "source": "hotpotqa",
  "split": "validation"
}
```

## Regenerating

```bash
python scripts/prepare_hotpot_teacher_guidance.py \
  --subset distractor --split validation --limit 10 --shuffle \
  --out_dir data/datasets/hotpot_teacher_guidance
```

The generated `.jsonl` files are git-ignored; only this README is tracked.
